## Как начать

1. Откройте ноутбук по ссылке преподавателя и сохраните копию: **Файл → Сохранить копию на Диске**.
2. Сохраните токен команды в секретах Colab (значок ключа слева) под именем `ECON_TOKEN`.
3. Запустите ячейку «Подключение». Она скачивает этот репозиторий и подключает пакет — ничего
   устанавливать не нужно.

```python
from econlab import City
city = City(TOKEN, url=SERVER_URL)
city.status()
```

## Запас попыток

Весь запас доступен сразу и до срока сдачи: **600 попыток ярмарки, 600 попыток фестиваля, 60 эфиров радио**
(по 36 песен).

## Что умеет `City`

| Метод | Что делает |
| --- | --- |
| `city.status()` | срок сдачи, результат, сколько попыток использовано |
| `city.K` | бонус ярмарки за три совпадения в вашем городе |
| `city.rename(name, coat)` | название и герб города |
| `city.fair(kind, lot)` | попытка на ярмарке: вид товара 0–5, вложение 1–5 ящиков |
| `city.festival(target, lot)` | попытка на фестивале: квартал 0–36, `"west"` (1–18) или `"east"` (19–36) |
| `city.catalog()` | песни радио: название, жанр, уровень популярности |
| `city.radio_state()` | номер эфира, номер следующей песни, `m`, предыдущий эфир |
| `city.radio_step(buy, lot)` | решение по следующей песне: купить паузу после неё или нет |
| `city.play_broadcast(decide, lot)` | проиграть эфир целиком (36 песен) по вашему правилу `decide` |
| `city.radio_log(n)`, `city.radio_logs()` | эфирные справки: порядок песен в прошедших эфирах |
| `city.history(activity)` | ваша история попыток (`"fair"`, `"festival"`, `"radio"`) таблицей pandas |
| `city.claim(...)`, `city.claims()` | заявки в Экономическую палату и их статусы |
| `city.forecast(mean, low, high)` | прогноз итогового результата и диапазон, куда он попадёт с вероятностью 0,9 |
| `city.country()`, `city.news()` | карта страны и лента новостей |

Подробности — в подсказках: `help(city.fair)`.

## Офлайн-режим

```python
from econlab import MockCity
offline = MockCity(K=25, seed=1)
```

`MockCity` повторяет правила стенда, но все активности в нём **честные**, а попытки не тратятся.
Он нужен, чтобы отлаживать код, графики и ботов. Эксплойт в офлайн-режиме не найти.

## Помощники

- `econlab.stats`: `mean_range`, `freq_range`, `z_score`, `pairs`, `transition_table`, `cumulative_mean`,
  `neighbors_kept`, `normal_interval`.
- `econlab.plots`: `quarter_frequencies`, `neighbor_scatter`, `transition_heatmap`,
  `cumulative_return`, `shuffle_comparison`.
- `econlab.simulate_neighbors(riffle, k)`: прогон вашей модели тасовки.

## Частые ошибки

| Сообщение | Что делать |
| --- | --- |
| «Все … попыток использованы» | запас этой активности закончился |
| «Стенд ещё не открыт» / «Срок сдачи прошёл» | см. даты в `city.status()` |
| «Токен не найден» | проверьте секрет `ECON_TOKEN` или попросите преподавателя выдать новый токен |
| «Слишком много запросов» | пакет сам делает паузы; не запускайте несколько ботов одновременно |

## Правила

- Не публикуйте токен и не передавайте его другим командам.
- Не пытайтесь нагружать или ломать стенд: эксплойты ищутся в данных, а не в сервере.
- Монеты и товар виртуальные и ни на что не обмениваются.
